- 변경: `ollama`를 독립 작업자가 아니라 goose가 사용하는 로컬 LLM 런타임으로 정리했다. `OLLAMA.md`는 제거 대상이 되었고, goose 지시와 설정에 모델 백엔드 설명만 남겼다.
- 검증: 설정 JSON 파싱 통과. `python Harness/scripts/verify_project.py` 통과.
- 남은 것: 대상 JavaScript 프로젝트에 이식한 뒤 goose의 실제 ollama 모델 설정은 로컬 환경에서 별도 지정 필요
